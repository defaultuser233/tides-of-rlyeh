关键技术概念

项目 D:\\Documents\\tides-of-rlyeh（由 rust-fps 更名；游戏名 TIDES OF R'LYEH / 拉莱耶的潮声，提交 59ba77a）。Rust + macroquad 0.4.16，手写程序化方块几何体，角色/武器无贴图，烘焙顶点光照，无模型加载器（没有 load\_model，没有 OBJ 解析器）。

固定步长 1/120 秒子步（每帧最多 8 步）；空气阻力被刻意设计为重新抹平 bhop（连跳）所存积的速度。

macroquad 事实（源码核实）：3D shader 为 color \* texture2D(Texture, uv)；Vertex { position: Vec3, uv: Vec2, color: \[u8;4], normal: Vec4 }；normal 从未被 macroquad 读取 → 相当于一条免费的 4 浮点通道；Mesh.indices 是 Vec<u16>（65536 顶点上限，每个 Mesh 仅一张贴图）；Conf 没有雾/光照字段；自定义贴图绝不能命名为 Texture/\_ScreenTexture（会 panic）；MaterialParams 运行时不可变；MAX\_PIPELINES = 32；\_ScreenTexture 采用子串匹配；\_Time = vec4(time, sin, cos, 0)；数组 uniform 需使用 set\_uniform\_array；draw\_mesh 没有 \_ex 变体。

武器数据模型（已实现，超出规格）：SlotId / InterfaceId / PartId / SlotDef{id,accepts,max\_parts} / PartDef{id,slot,interface,subslots,mods} / WeaponDef{class,fire\_modes,infinite\_ammo,melee,base:\[Value;STAT\_COUNT],slots} / WeaponBuild{entries:\[BuildEntry{slot,part,roll}]} / ResolvedStats；纯函数 resolve（约 814 行）、validate（约 888 行）、reachable\_slots（约 763 行，对递归子槽位做不动点遍历）、Value::Range + 每实例 roll（随机滚动取值）。CATALOG = parts::SHIPPED（测试构建中额外加入 demo\_parts）。

护甲模型：ARMOR\_MAX = 50.0，let absorbed = (amount \* 0.65).min(\*armor) —— 单一护甲池、覆盖所有身体部位，没有头盔/腿部区分、没有视角抖动（aimpunch）、没有穿透机制。

分数是个死数字：enemy::score 每次击杀 25–2500，加上 mission.score\_bonus 500–6000；仅在 HUD 中被格式化为字符串；不持久化、不解锁任何内容、没有最高分记录。

unlocked / last\_mission 会持久化；LEGACY\_DIRS = \["eldritch-front", "steel-front"]；配置目录为 tides-of-rlyeh。

波次研究（来源已核实，\*.wiki.gg / Halopedia / RoR2 wiki）：ULTRAKILL Cyber Grind 预算为 10 + Σ(3+⌊w/3⌋)（第 5 波 = 28，第 10 波 = 55），造价（Filth 1、Stray 2、Schism 5、Malicious Face 13+5、Cerberus 16+2、Hideous Mass 45），精英规则"出 1 个则锁定 2 波"，每波重置生命/呼吸，起始波解锁条件 = 曾到达 2× 波数；DRG 共 5 个难度（敌人伤害倍率 0.50/0.70/1.20/2.00/2.80，每名玩家仇恨上限 32 个地面 + 32 个空中，总数 60），敌人造价（Grunt 10、Swarmer 6、Praetorian 90、Bulk Detonator 120）；Halo Firefight 1 回合 = 5 波，每个 Set 有 90 秒奖励回合（Bonus Round）；RoR2 系数 = (playerFactor + min×0.0506×difficultyValue×playerCount^0.2) × 1.15^stages，商店 baseCost × coeff^1.25，精英生成倍率 = 6× / 36×；Vermintide 2 天赋在 5/10/15/20/25/30 级解锁，共 6 行 × 每行 3 个选项；DRG 层级 2–3 选 1，价格 1200/2000/2800/4800/5600，超频（Overclocks）分为 Clean/Balanced/Unstable，总计 160 个。
